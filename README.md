# Реестр.xlsx

Универсальный локальный инструмент для автоматического сбора данных из Excel-документов в единый реестр.

Приложение сканирует папку с `.xlsx/.xlsm/.xls` файлами, извлекает значения из указанных ячеек и формирует итоговый файл `Реестр.xlsx`.

---

# Возможности

* Сканирование папки с Excel-файлами
* Настраиваемые колонки реестра
* Поддержка:

  * текста
  * дат
  * чисел
* Проверка обязательных полей
* Отображение ошибок и пустых значений
* Поиск и сортировка таблицы
* Drag-and-drop сортировка колонок
* Экспорт итогового реестра в Excel
* Веб-интерфейс без сторонних фронтенд-фреймворков
* CLI-режим для автоматизации

---

# Интерфейс

## Основной режим

* выбор папки
* сканирование документов
* просмотр реестра
* экспорт `Реестр.xlsx`

## Настройки

Можно настроить:

* название колонок
* адреса ячеек
* тип данных
* обязательность заполнения

Настройки сохраняются в:

```bash
config.json
```

```bash

```

# Настройка колонок

Пример `config.json`:

```json
{
  "columns": [
    {
      "name": "Поставщик",
      "cell": "E2",
      "type": "text",
      "required": false
    },
    {
      "name": "Дата",
      "cell": "E4",
      "type": "date",
      "required": true
    },
    {
      "name": "Сумма",
      "cell": "L9",
      "type": "number",
      "required": false
    }
  ]
}
```

---

# Типы данных

| Тип    | Описание |
| ------ | -------- |
| text   | Текст    |
| date   | Дата     |
| number | Число    |

---

# Проверка обязательных полей

Если поле отмечено как обязательное:

```json
"required": true
```

и значение отсутствует — файл попадёт в список ошибок.

# Поддерживаемые форматы

* `.xlsx`
* `.xlsm`
* `.xls`

# Особенности работы

## Что сканируется

Приложение:

* открывает каждый Excel-файл
* читает значения указанных ячеек
* формирует единый реестр

---

## Что игнорируется

Файл:

```bash
Реестр.xlsx
```

игнорируется при сканировании, чтобы избежать повторного чтения итогового файла.

# Возможные ошибки

| Ошибка                   | Причина              |
| ------------------------ | -------------------- |
| Папка не найдена         | Неверный путь        |
| Неверный адрес ячейки    | Ошибка в config.json |
| Пустое обязательное поле | Не заполнены данные  |
| Ошибка открытия файла    | Повреждённый Excel   |
